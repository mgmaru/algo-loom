- ファイル名は`YYYY-MM-DD-<run-id>.md`とします。
- [記録テンプレート](run-record-template.md)から作成します。
- 下書き、生ログ、検証コード、一時出力、認証情報、問題文、入出力例の実値、提出用ソースコードはこの`results/`へ保存しません。再利用可能な検証支援コードは[`scripts/verification/`](../../../../scripts/verification/)へ分離します。

- 設計判断は成果物内で確定せず、該当する正本文書を別の変更として更新します。

## `p0-02`後の設計変更

2026年8月11日に、過去の観測結果を変更せず、方式Cを`V-02`の検証専用経路として許可し、方式AをMVP製品候補として別のP0 `V-10`で検証する方針へ変更しました。正本は[AtCoder認証設計](../../../architecture/atcoder-authentication.md)と[`JudgeAdapter`技術検証計画](../../../project/judge-adapter-verification.md)です。

方式Cによる`V-02`は`p0-04`、`V-05`は`p0-07`で合格しました。`p0-10`でCDPをCloudflare非互換の原因として特定し、`p0-11`で通常ChromeのV-03経路を作成しました。`p0-12`で通常ChromeからCloudflare互換性、本人アカウント、フォーム、CPythonまで確認し、`p0-14`では人によるTurnstileと明示承認後のフォーム`submit`イベントまで到達しました。しかし、ソース空欄の報告後も結果ページと提出IDを得られず、network POSTの到達も計測していません。再提出せず、`V-03`を送信状態不明の未合格とします。`V-04`、`V-10`も未合格であり、P0全体とMVP実装開始条件は未充足です。

## 関連する検証支援コード

[`atcoder_v02_session_check.py`](../../../../scripts/verification/atcoder_v02_session_check.py)は、`p0-04`で記録した方式Cの通信条件と分類を再現するため、実行後に再構成した版です。`p0-04`で使用して削除したファイルとバイト単位で同一とは扱わず、このコードやローカルテストだけを実サービスの証拠にしません。

[`atcoder_v03_submit.py`](../../../../scripts/verification/atcoder_v03_submit.py)は、当日の`V-02`再確認、Cloudflare公式の`cf-mitigated`分類、提出フォーム構造とTurnstile関連付け、`V-05`、提出ゲート、POST上限1回、提出IDの一意な取得を順番に適用する検証支援コードです。`p0-07`では、AtCoder公式JavaScript実行前の問題別・名前なし言語`select`を実サービスで解析し、`V-05`の合格を確認しました。その後の対象フォーム内Turnstile停止条件によりPOSTを呼ぶ経路へは到達していません。`V-05`の合格を`V-03`の合格とは扱いません。

[`atcoder_v03_turnstile_probe.mjs`](../../../../scripts/verification/atcoder_v03_turnstile_probe.mjs)は、空の専用プロファイルと可視Chromeを使い、JavaScript実行後のTurnstile応答欄を値を返さず観測する補助コードです。`p0-08`ではログイン段階で中止したため、実行時応答欄の実サービス証拠は得ていません。実行時版にあったログイン前のページ注入を除く二段階へ実行後に修正しており、現在のコードやローカルテストを`p0-08`の成功証拠にはしません。

修正版を実サービスで使用した`p0-09`でも、ログイン時のCloudflare検証失敗により対象提出ページへ到達しませんでした。ページ注入と既存Chrome同時稼働を除いた事実は保持しますが、Cloudflareの内部理由やブラウザ制御チャネルの寄与は断定しません。現在のコードを、同じ方式の無条件な再試行やBot対策の回避へ使用しません。

[`atcoder_v03_browser_submit.mjs`](../../../../scripts/verification/atcoder_v03_browser_submit.mjs)と[`atcoder_v03_browser_extension/`](../../../../scripts/verification/atcoder_v03_browser_extension/)は、`p0-10`の原因特定後に作成した通常ChromeのV-03経路です。利用者が空の専用プロファイルへ検証専用拡張を手動読込し、ログイン、エディタ切替、Turnstile、AtCoder本体の提出ボタンを操作します。拡張はCookie、CSRFトークン、Turnstileトークンの値を読まず、提出操作を自動化しません。`p0-14`後の版は、可視プレーンテキスト欄と`FormData`のソース一致を送信前に二重確認します。修正版のローカルテストだけを実サービスのV-03合格証拠にしません。
