# JudgeAdapter技術検証の成果物

このディレクトリには、[`JudgeAdapter`技術検証計画](../../../project/judge-adapter-verification.md)を実行して確定した匿名化済みの成果物と、その作成に使う文書だけを保存します。

- ファイル名は`YYYY-MM-DD-<run-id>.md`とします。
- [記録テンプレート](run-record-template.md)から作成します。
- 下書き、生ログ、検証コード、一時出力、認証情報、問題文、入出力例の実値、提出用ソースコードは保存しません。
- 再実施した場合は既存記録を上書きせず、新しい実行IDのファイルを追加します。
- 設計判断は成果物内で確定せず、該当する正本文書を別の変更として更新します。
